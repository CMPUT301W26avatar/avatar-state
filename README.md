## Instructions

### Logging as an Existing User

Enter your user details into the required textfields (Email Address and Password) and click Login. This should take you MainActivity (home).

### Logging in as Guest

Click Login as Guest button on signin screen. This should take you MainActivity (home). The app will ask you if you would like to receive notifications from the app.

### Creating a new user

Click Register button on signin screen. This should take you signupActivity. Enter required text inputs (email, password etc.) and then click Sign Up. If the inputs are valid, your account will be created and you will be taken to MainActivity (home). The app will ask you if you would like to receive notifications from the app.

### Joining/Leaving the waitlist for an Event

Click on any event icon in the home screen or search screen. This should take you to EventDetailsActivity. You will the event details (title, description etc.). Click the Join Waitlist button at the bottom to join the waitlist. Click Leave Waitlist if you want to leave after successfully joining the waitlist. A Toast popup message will notify you of the status of your actions.

### Creating/Updating Events

Click on the event management screen (4th icon from the left at the bottom). Click the + button to create a new event. Enter the required input (Title, event capacity, event date etc.). Click Create Event to create the event. This should take you back to the event management screen. You should see the event you created. If you click the pen icon, you will be able to edit event details. Click Update Event to save your changes. You will be taken back to event management screen.

### Editing User Details

Click on the UserDetailsActivity (last icon from the left at the bottom). You can click the Log Out button at the bottom to log out the current user. Click Details to see your user details. Enter input into the textfields (email, password etc.) and click the Save button to save your changes.
